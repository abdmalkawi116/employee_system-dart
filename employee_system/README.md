# Employee & Payroll System (Dart)

Run:  `dart run bin/main.dart`

bin/main.dart          entry point
lib/models.dart        Payable, Taxable, Employee, FullTimeEmployee, Manager, PartTimeEmployee, EmployeeFactory
lib/services.dart      EmployeeManager (List/Map/Set), PayrollService, FileStorage, SampleDatabase
lib/utils.dart         Formatter (output), InputHelper (input)
lib/employees_data.dart  raw starting data only (names, departments, numbers)
lib/payroll_app.dart   the interactive menu
